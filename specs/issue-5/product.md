# 用户岗位模块 — 产品规格

## 背景

系统中已有用户模块（SysUser）和岗位模块（SysPosition），但两者之间没有关联关系。需要建立用户与岗位的多对多关联，并确保删除岗位时有关联用户的保护机制。

## 目标

1. 建立用户与岗位的多对多关联关系
2. 支持为用户绑定/解绑岗位
3. 支持按用户查询所属岗位、按岗位查询关联用户
4. 删除岗位时检查是否有用户关联，有关联用户时禁止删除

## 功能规格

### 用户-岗位关联管理

| 功能 | 说明 |
|------|------|
| 绑定岗位 | 为用户绑定一个岗位，需校验用户和岗位存在性，以及是否已绑定 |
| 解绑岗位 | 移除用户的一个岗位绑定 |
| 查询用户岗位 | 根据用户 ID 查询其所有岗位 |
| 查询岗位用户 | 根据岗位 ID 查询其所有关联用户 |

### 岗位删除保护

岗位删除时增加业务规则校验：
- 如果该岗位有关联用户（至少一个用户被分配了该岗位），则删除失败
- 只有当该岗位没有任何用户关联时，才允许删除

## 排除范围

- 不修改用户表结构
- 不修改岗位表结构
- 不涉及前端页面
