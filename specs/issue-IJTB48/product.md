# 产品规格：角色关联权限模块

## 概述

为角色（SysRole）和权限（SysPermission）建立多对多关联，实现"为角色分配权限"和"查询角色拥有的权限"等核心功能。

## 目标

- 管理员可以为任意角色分配一组权限
- 管理员可以查看某个角色当前拥有的所有权限
- 管理员可以移除角色的某个权限关联
- 删除角色或权限时，自动清理关联记录

## 非目标

- 不实现用户-角色的直接关联（用户通过角色间接获得权限）
- 不实现权限继承/传播逻辑
- 不实现前端 UI

## 用户场景

### 场景 1：为角色分配权限

1. 管理员选择一个角色（如"编辑员"）
2. 管理员从权限列表中选择多个权限（如"文章管理"、"评论管理"）
3. 系统保存关联关系
4. 角色的权限列表更新为最新分配

### 场景 2：查询角色的权限

1. 管理员查看某个角色详情
2. 系统返回该角色关联的所有权限列表

### 场景 3：移除角色权限关联

1. 管理员从角色的权限列表中删除某个权限
2. 系统移除该关联记录

### 场景 4：级联删除

1. 管理员删除某个角色 → 系统自动删除该角色的所有权限关联
2. 管理员删除某个权限 → 系统自动删除该权限的所有角色关联

## 验收标准

| # | 验收条件 | 验证方式 |
|---|---------|---------|
| AC1 | 可以为角色批量分配权限（全量替换） | API 测试 |
| AC2 | 可以按角色 ID 查询关联的权限列表 | API 测试 |
| AC3 | 可以移除角色与单个权限的关联 | API 测试 |
| AC4 | 删除角色时，其关联记录自动删除 | 单元测试 |
| AC5 | 删除权限时，其关联记录自动删除 | 单元测试 |
| AC6 | 重复分配相同角色-权限不产生重复记录 | 单元测试 |

## 边缘情况

- 分配空的权限列表：清除该角色的所有权限关联
- 角色不存在时分配权限：返回错误
- 权限不存在时分配：返回错误
